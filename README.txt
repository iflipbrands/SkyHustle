Sky Hustle — web build

Setup:
  npm install
  npm start
  Open http://localhost:3000

Folders:
  assets/       Shared atlases, generated placeholders (postinstall)
  characters/   Ceez / Ray models and textures
  animations/   FBX clips + level1-end video
  ui/           Menu and HUD images
  audio/        Music
  environment/  Street, city GLB, dumpster, asphalt
  js/           Game code
